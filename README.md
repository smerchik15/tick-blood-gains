# КЛЕЩ · Blood Gains

Автоматический шутер с развитием клеща, исследованием карты, четырьмя сложностями и боссами. Текущая версия: **4.3.1 — Sound & Gear**.

**Играть:** https://tick-wild-fur-v2.noblebell32.chatgpt.site/

## Запуск и проверка

- Открой `game.html` в браузере: игра, графика и звуки находятся внутри одного файла. Личные рекорды и сохранения работают локально.
- Для проверки кода нужен Node.js 20 или новее. Внешние npm-зависимости не требуются.

```sh
npm test
npm run build
node scripts/validate-artifact.mjs
```

`npm test` проверяет бой, сочетания модификаторов, сохранения, экономику, награды, экипировку, звуковые события и серверный подсчёт очков. Команда сборки создаёт `dist/server/index.js` — Worker с той же HTML-игрой и API рейтинга. Общий рейтинг требует развёрнутого Worker с привязкой D1 `DB` и миграциями из `drizzle/`; при открытии HTML с диска доступны личные рекорды.

## Где менять игру

- `game.html` — единственный исходник клиента; HTML-версия и сайт собираются из него.
- `worker/handler.mjs` — API общего рейтинга и проверка результатов.
- `tests/` — проверки механик и рейтинга.
- `scripts/` — сборка и проверка выходного Worker.
- `drizzle/` — схема и миграции базы рейтинга.
- `.openai/hosting.json` — конфигурация существующего сайта; не содержит паролей или токенов.

Папка `dist/` генерируется при сборке и не хранится в GitHub. Сохранения игроков не входят в репозиторий: они находятся в браузере игрока; общий рейтинг хранится отдельно в базе сайта. Обновление исходников на GitHub само по себе не публикует новую версию сайта.

## Изменения 4.3

- Эффекты экипировки пересчитываются при смене набора и продолжении сохранённого рана. Вампиризм от снятого клыка отключается; источники лечения перечислены в паузе.
- Пирс и чейн сочетаются, сохраняя пробития после отскока. Их снаряды и копии дрона не создают клив, в том числе после расходования счётчиков.
- Добавлен Куромёт за 10 000 слизи: модель курицы и звук каждого десятого основного выстрела. Эффект предмета в магазине не раскрывается.
- Добавлены ненавязчивые звуки, пользовательские записи победы над боссом и гибели, громкость и отключение звука.
- Интерфейс учитывает размер видимой области и поворот экрана. Толщина полоски опыта — 12 px.

V-Mode, секретные предметы и уровни запланированы на последующие итерации.

## Изменения 4.3.1
