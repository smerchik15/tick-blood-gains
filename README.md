# КЛЕЩ · Blood Gains

Автоматический шутер с развитием клеща, исследованием карты, пятью сложностями и боссами. Текущая версия: **4.9.1-test**.

**Играть:** https://tick-wild-fur-v2.noblebell32.chatgpt.site/

## Запуск и проверка

- Открой `game.html` в браузере: игра, графика и звуки находятся внутри одного файла. Личные рекорды и сохранения работают локально.
- Для проверки кода нужен Node.js 20 или новее. Внешние npm-зависимости не требуются.

```sh
npm test
npm run build
node scripts/validate-artifact.mjs
```

`npm test` проверяет баланс меты, вероятности и выплаты «Гамбино», расходники, подготовку гнезда, замену мутаций, сохранения, перенос прогресса и серверный подсчёт очков. Старые проверки баланса 4.8 сохранены в tests/balance.cjs как исторический набор; их прежние численные ожидания не применяются к новому балансу. Команда сборки создаёт `dist/server/index.js` — Worker с той же HTML-игрой и API рейтинга. Общий рейтинг требует развёрнутого Worker с привязкой D1 `DB` и миграциями из `drizzle/`; при открытии HTML с диска доступны личные рекорды.

## Где менять игру

- `game.html` — единственный исходник клиента; HTML-версия и сайт собираются из него.
- `worker/handler.mjs` — API общего рейтинга и проверка результатов.
- `tests/` — проверки механик и рейтинга.
- `scripts/` — сборка и проверка выходного Worker.
- `drizzle/` — схема и миграции базы рейтинга.
- `.openai/hosting.json` — конфигурация существующего сайта; не содержит паролей или токенов.

Папка `dist/` генерируется при сборке и не хранится в GitHub. Сохранения игроков не входят в репозиторий: они находятся в браузере игрока; общий рейтинг хранится отдельно в базе сайта. Обновление исходников на GitHub само по себе не публикует новую версию сайта.

## Изменения 4.4–4.7

## Изменения 4.8

- Возвращены прежние атаки Короля Блох и стрекозы; у остальных боссов исправлены центральные выстрелы, увеличены дальность и плотность залпов. Прицел фиксируется перед выстрелом, оставляя время на уклонение.
- Вошка Mandy и новый одиннадцатый уровень: «Собачий кайф», босс-рука с прочёсом, огненным следом, ударом по отмеченной точке и веерным прочёсом.
- На невозможной сложности и в V-Mode — 28 луж шампуня вместо 7, явный химический урон и сохранение предупреждения перед активацией.
- Гнездо снова выглядит как гнездо из шерсти и яиц. Бонусы на карте сохраняют свои функции.
- Добавлены колорадские подрывники и водомерки-слайдеры, их предупреждения, модели, сохранения и учёт в рейтинге.
- Четыре редкости мутаций с цветом и подписью. Вес редкостей на карточку: 58/25/12/5; при исчерпании категории веса нормализуются. Внутри категории моды равновероятны.
- Убрана несовместимость взрывов с пробитием и цепями. Добавлены эпические «Взрывные железы» и «Длинная цепь». Взрывы не запускают другие взрывы; копии дрона не взрываются.
- Блок щитом прыжка или рывка даёт +18% скорости на 5 секунд; бонус не складывается, повторная награда через 6 секунд.

Баланс экипировки, новые траты крови и переработка элементов в эту версию не входят.


## Изменения 4.9-test

- Ограничены постоянные прибавки меты. При максимуме мета даёт около 24,2% итогового базового DPS без мутаций; это измерение урона, а не всей силы персонажа.
- Атакующая экипировка зависит от боевых мутаций: редкий залп ракеты раз в 9 секунд, поддержка дрона и активные поля.
- Добавлены подготовка следующего гнезда, разовая защита, временные усиления и платная замена конкретной карточки мутации. Цены растут в забеге и сбрасываются в новом.
- В правом верхнем углу карты открыто «Гамбино». Используется только кровь текущего забега. Ставка: 180, затем +40 за прокрутку, максимум 1200.
- Возможны проигрыш, частичный возврат, временные бонусы и экипировка. Шанс выплаты десятикратной ставки — 1%; начисление включает всю выплату, ставка перед этим списывается.
- Прогресс предыдущей версии копируется при первом запуске, если сохранения 4.9 ещё нет. Исходные сохранения не удаляются и не перезаписываются. Сохранение уже начатого теста 4.9 имеет приоритет.
- Экспериментальные забеги вне общего рейтинга. Глубокая переработка элементов пока не включена.

Автоматические проверки не подтверждают баланс полного прохождения: невозможную сложность и управление на настоящих телефонах ещё нужно оценить игровыми забегами.


## Обратная связь · 4.9.1

- Кнопки «Обратная связь» в главном меню и паузе открывают `/feedback`.
- Игрок отправляет сообщение без входа и email. Ник необязателен. Есть категории ошибки, предложения, баланса и другого; длина текста — 10–4000 символов.
- Отзывы сохраняются в D1, а не в браузере или GitHub. Ограничение — до 5 обращений за 10 минут; повторная отправка с тем же номером не создаёт дубль. Для ограничения используется меняющийся ежедневно хеш сетевого адреса; сам адрес и email отправителя в записи не сохраняются.
- `/feedback/inbox` — закрытая страница владельца после входа через ChatGPT. Доступ проверяется на сервере для чтения и смены статусов: новое, прочитано, готово. Есть фильтр и постраничная загрузка.
- Runtime-секрет `FEEDBACK_OWNER_EMAIL` настраивается в Sites; значение не входит в исходники. Вход остальных посетителей для игры или отправки отзывов не требуется.
- Схема базы добавляется миграцией `0002_feedback.sql`. Существующие игровые сохранения и рейтинг не меняются.
- Проверки: `node tests/feedback.mjs` проверяет реальную SQLite-схему, сохранение, доступ владельца, фильтры, статусы, ограничения и безопасное отображение текста.
