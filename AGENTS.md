# Экономный режим разработки Клеща

- По умолчанию выбирай наименьшие достаточные усилия. Маленькая правка: точечное чтение, минимальный diff, одна проверка поведения, одна сборка и публикация.
- Не читай целиком game.html: внутри большие встроенные медиа. Используй поиск с ограничением длины строки и короткие диапазоны.
- Для баланса, сохранений и боевых систем проверяй затронутые механики; полный набор запускай один раз перед выпуском существенного изменения.
- Повышай глубину анализа только при неопределённости, ошибке проверки или существенном риске. Не проводи повторный аудит неизменённых частей.
- Когда среда поддерживает выбор модели, используй лёгкую модель и Low для локальных правок; среднюю модель и Medium для боевой логики и миграций; высокий уровень только для нерешённой сложной проблемы. Не утверждай, что модель переключена, если у тебя нет такого управления.
- Не создавай параллельных агентов без отдельного запроса пользователя. Не добавляй автоматизации по расписанию для выбора моделей.
- Публикуй на существующий сайт и GitHub после завершения согласованных правок. Сохраняй идентичность сайта, доступ и хранилища.
